# Code Complexity Atlas

Visualise code complexity and technical-debt hotspots in 3D.

## Features

- Three.js 3D visualisation
- Projects and reports
- Documentation

## Tech Stack

- Vite
- React
- TypeScript
- Tailwind CSS
- shadcn/ui (Radix UI)
- TanStack Query
- React Router
- Three.js

## Getting Started

```bash
git clone https://github.com/ghostland-dev/code-heat-atlas.git
cd code-heat-atlas
npm install
npm run dev
```

Other scripts:

- `npm run build`: vite build
- `npm run lint`: eslint .
- `npm run preview`: vite preview
